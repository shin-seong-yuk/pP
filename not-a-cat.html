Not A Cat

고양이 사이에 숨은 삵을 찾아라.

고양이 마피아 조직에 숨어든 첩자 ‘삵’을 찾는 직업 기반 심리 게임입니다. 각 플레이어는 직업에 따른 특성과 능력을 활용하고, 미션과 대화에서 얻은 정보로 서로의 정체를 추리합니다.

01 / CONCEPT

귀여운 고양이들 사이에서
시작되는 의심과 심리전.

플레이어들은 고양이 마피아 조직의 구성원이 되어 함께 행동하지만, 그중에는 첩자 삵이 숨어 있습니다. 각 고양이와 삵은 서로 다른 직업과 능력을 가지며, 플레이어는 행동과 대화를 관찰해 누가 조직을 속이고 있는지 판단합니다.

02 / GAME DESIGN

추리의 근거가 생기는 공간과 규칙

맵 구성

플레이어가 이동하며 서로를 마주치고, 흩어지고, 의심할 상황이 만들어지도록 방과 이동 경로를 구성했습니다.

직업 설계 · 꾹꾹이 고양이

삵 진영의 직업으로, 같은 대상에게 0.5m 이내에서 꾹꾹이 9스택을 쌓으면 원하는 때 원거리 처치가 가능하도록 설계했습니다. 귀여운 행동을 위험한 능력으로 바꿔 콘셉트를 살렸습니다. 현재 미구현이며 프로토타입 제작 후 팀 내부 QA를 진행할 예정입니다.

게임 로직

역할 배정부터 행동, 미션, 대화와 판단으로 이어지는 전체 게임 흐름과 규칙을 설정했습니다.

미션 · 중심은 사람과 추리

미션이 주된 재미가 되어 사회 추리가 약해지지 않도록 간단한 조작과 빠른 이해를 우선했습니다. 캣잎 포장은 스크롤 7번으로 완료하고, 음식 세팅은 이동과 시각적 변화로 마피아 저택의 연회 분위기를 표현하도록 기획했습니다.

ROLE DESIGN / PLANNED RULES

강한 능력에 준비와 중단 조건을.

같은 대상에게 0.5m 이내에서 접근해 스택을 쌓고, 재사용 대기 10초를 적용하도록 설계했습니다. 첫 사용이 즉시 가능하다면 9회 사이 8번의 대기로 이론상 최소 준비 시간은 80초입니다. 회의가 열리면 누적 스택을 초기화해 준비가 중단될 수 있게 했습니다.

현재 설계 단계입니다. 프로토타입을 제작해 팀 내부 QA를 진행할 예정이며, 접근 난이도와 회의 빈도에 따른 실제 준비 시간과 밸런스는 확인할 부분입니다.

MISSION DESIGN / IMPLEMENTED

현재 행동에 필요한 위치를 보여주기.

캣잎 포장과 음식 세팅은 구현 후 직접 동작을 확인했습니다. 캣잎 포장은 스크롤 7번으로 완료하는 간단한 조작을 사용합니다.

  1. 음식 발견: 부엌의 음식에 하이라이트를 표시합니다.
  2. 집기와 운반: 음식에 가까이 가서 커서를 올리고 F키로 집은 뒤 식당으로 이동합니다.
  3. 상태별 안내: 음식을 든 사람에게만 긴 식탁의 세 배치 지점을 하이라이트로 보여줍니다.
  4. 놓기와 완료: 한 배치 지점에 가까이 가서 커서를 올리고 F키를 누르면 음식이 놓이고 미션이 완료됩니다.

집기와 놓기는 같은 F키로 통일하고, 운반 상태에 맞는 위치 정보를 제공합니다. 간단한 미션 안에서 직접 이동과 시각적 변화를 통해 저택의 연회 분위기를 표현했습니다.

03 / PROTOTYPING

기획한 규칙을 실제 플레이로 연결

맵과 미션을 직접 구현하고, 직업과 게임 규칙이 한 판의 흐름 안에서 동작하도록 로직을 연결했습니다. 기획과 개발을 함께 담당하며 아이디어가 구현 가능한 구조인지 빠르게 확인하고, 실제 플레이에 맞춰 조정했습니다.

04 / COMMUNICATION

심리전의 중심이 되는 대화 시스템

상황과 단서를 교환할 수 있도록 텍스트 채팅과 보이스 채팅을 구현했습니다. 플레이어의 말과 침묵, 정보의 공유 방식까지 게임의 판단 재료가 되도록 심리전과 소통 시스템을 연결했습니다.

05 / COLLABORATION

서로 다른 우려에서 합의점을 찾기

저는 검증된 기본 구조를 먼저 만들고 차별화 기능을 얹고 싶었고, 동료는 고유한 아이디어를 먼저 정해야 자연스럽게 융합할 수 있다고 보았습니다. 동료의 완성도에 대한 우려를 인정하면서, 개발이 늦어지면 출시 일정도 지연될 수 있다는 점을 설명했습니다.

기본 구조 개발을 이어가는 동시에 아이디어 회의를 꾸준히 병행하는 방안을 제안했고, 팀이 이에 합의해 현재 함께 진행하고 있습니다. 기획의 방향과 구현 일정을 함께 고려하는 조율을 경험했습니다.
