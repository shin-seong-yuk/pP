# 신성욱 게임 기획 포트폴리오 (202355547)

이 폴더는 게임 기획자 버전입니다. 맵·전투·규칙·동선·미션을 폭넓게 설계한 경험과 새로운 재미를 위한 시도, 직접 플레이하며 기획을 검증하는 역량을 중심으로 구성했습니다. 실제 기획·개발 담당 범위와 확인된 결과는 유지합니다.

기존 Vercel 주소: https://shinswportfolio.vercel.app/ (이 폴더를 배포하기 전까지는 기존 온라인 버전입니다.)

## 두 버전 보관

- 기획자 버전: 현재 `portfolio-draft` 폴더. 기존 Git 저장소에서 계속 관리합니다.
- 개발자 원본: 옆 폴더 `portfolio-developer-backup-20261014`. 변경 전 웹사이트 파일과 이미지·영상·실행 서버를 그대로 보관했습니다. Git 내부 폴더는 제외했습니다.
- 개발자 백업 ZIP: `../202355547_신성욱_개발자포트폴리오_백업_20261014.zip`.
- 두 폴더 모두 아래 방법으로 독립 실행할 수 있습니다. 개발자 버전을 다시 배포하려면 백업 폴더를 별도 프로젝트의 소스로 사용하세요.

## 실행 방법

압축을 푼 뒤 이 폴더에서 터미널을 열고 아래 중 하나를 실행합니다.

```powershell
node server.cjs
```

브라우저에서 `http://localhost:8000`으로 접속합니다. `index.html`을 직접 열어도 기본 콘텐츠는 보이지만, 로컬 서버에서 실행해야 브라우저별 영상·3D 리소스 제한을 피할 수 있습니다. 인터넷 연결 없이 웹사이트 자체는 열리며, 외부 PLAY/GITHUB 링크는 인터넷이 필요합니다.

## 구성

- `index.html`: 한 페이지 포트폴리오. 소개, Elevator 대표 이미지, 연습장, 네 프로젝트 요약, 연락처.
- `project-modal.js`: 네 프로젝트의 상세 팝업. Elevator 대표 이미지나 본문 제목을 누르면 열리고, 팝업 안의 프로젝트 선택 버튼으로 다른 작품에 바로 이동할 수 있습니다. 연습장 표적은 해당 프로젝트 본문으로 스크롤합니다.
- `range-3d.js`, `range.js`: 3D 연습장과 대체 버전. 연습장을 사용하지 않아도 프로젝트 바로가기로 콘텐츠를 볼 수 있습니다.
- 모바일에서는 연습장 아래에 큰 프로젝트 바로가기 버튼이 추가로 표시됩니다. 허수아비는 터치로 공격할 수 있고, 명중 시 해당 프로젝트 본문으로 이동합니다.
- `style.css`, `range.css`: 데스크톱·모바일 스타일.
- `assets/`: 프로필 사진, 실제 게임 화면 이미지, 두 프로젝트의 소개 영상.
- 별도 프로젝트 HTML 파일: JavaScript 비활성화 환경의 예비 링크. 각 상세 페이지에도 프로젝트 선택 메뉴가 있습니다.

## 배포 안내

기획자 버전의 내용은 메인 페이지, 상세 팝업, JavaScript가 꺼졌을 때 열리는 네 상세 HTML에 반영했습니다. 기존 제출용 ZIP과 PDF는 이전 제출 기록이며 이번 수정으로 덮어쓰지 않았습니다. 온라인 사이트에 반영하려면 현재 기획자 버전을 커밋·푸시하거나 Vercel에서 배포해야 합니다.
